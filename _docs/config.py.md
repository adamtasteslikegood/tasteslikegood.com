## Overview

This module centralizes configuration and validation concerns for the Tastes Like Good application. It exposes functions to load the main application configuration from a JSON file, load the recipe JSON Schema used for validating recipe data, create a JSON Schema validator instance for that schema, and retrieve the Google API key from environment variables. The module also integrates environment variable loading and a project-specific value-key resolution helper to surface resolved configuration details to the application.

The implementation ties together on-disk JSON configuration, schema-based validation via jsonschema's Draft7Validator, and environment-driven secrets via dotenv. Callers use the provided functions to obtain parsed configuration objects, a ready-to-use validator for recipe data, and API keys required for external integrations, keeping these concerns encapsulated in one place.

- Uses python-dotenv (load_dotenv) to load environment variables from a .env file.
- Uses jsonschema Draft7Validator for schema-based validation of JSON data.
- Delegates project-specific configuration resolution to a helper (resolve_valkey_config) in a utils module.

## Maintenance Notes

- Load the application configuration from config.json so the rest of the application can access settings and paths.
- Load the recipe validation schema from recipe_schema.json for use when validating recipe payloads.
- Provide a Draft7Validator instance configured for the recipe schema to perform JSON Schema validation of recipe data.
- Read environment variables (including the Google API key) after loading .env so sensitive keys are available at runtime.
